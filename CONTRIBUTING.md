# Contributing

AI Conductor welcomes focused bug reports and pull requests. Before starting a large change,
open an issue describing the use case and proposed trust-boundary impact.

## Development checks

Use Python 3.12 or later on Linux. Bubblewrap is required for the shell-isolation tests.

```bash
cp config.example.json config.json
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 -m compileall -q ai_conductor tests
```

Keep machine paths, credentials, provider output, chat data, and generated bytecode out of commits.
Update tests and documentation with behavioral changes. Keep changes compatible with the local-only
security model described in `SECURITY.md`.

## Pull requests

- Explain the user-visible behavior and security implications.
- Keep commits scoped and use an identity you are comfortable publishing.
- Confirm that no generated files or private data appear anywhere in the submitted history.
- Do not weaken provider sandboxing, loopback checks, CSRF checks, or the passive board boundary
  without explicit discussion.
